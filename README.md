# COR AI piloting stimuli

Test repo for hosting Civic Online Reasoning classroom stimuli with GitHub Pages.

- `youth-turnout/` — simulated chatbot response on 2024 youth turnout (links to CIRCLE report)
- `death-penalty/` — simulated AI overview on whether the death penalty deters crime (links to NIJ document; Verifying Alignment practice #1)
- `eff/` — simulated chatbot response on the Electronic Frontier Foundation (links to Britannica; Verifying Alignment practice #2)

Pages carry a noindex tag so they stay out of search results.
